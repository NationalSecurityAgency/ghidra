Emulation: Injecting Taint

This plugin presents actions for injecting taint directly into the emulator's p-code. Depending on the current context (decompiler, disassembly, or p-code instruction), the actions select the left-most identifiable varnode and attempt to generate sleigh instructions to be injected into the emulated stream.

Actions

The plugin provides several actions which are enabled when the debugger's control-mode is set to emulation.

Toggle taint by array

This action toggles the taint of the given machine variable with an array of taint symbols, as described in the TaintPcodeUserOpLibrary

Toggle taint by var

This action toggles the taint the given machine variable with a single taint symbol.
