Data Types Table

The Data Types Table offers a way to view all data types from the Data Type Manager tree in a table view. This allows the user to find and work with types in ways that are not possible in a tree structure. The right-click menu of the table provides some actions that are found in the tree.

The Data Types Table can be shown using the Show Data Types Table action, which is available from the drop-down menu of the Data Type Manager's header.

Drag and Drop

You can drag types from the table to the tree to copy / move data types between categories and archives.

Actions

Select Data Types in Tree

This action will use the type selected in the table and select the type in the Data Type Manager tree. This will add to the current tree selection, allowing you to select multiple types in the tree by repeating the action.

Program Types Filter

This toggle action provides a way to quickly show only data types that belong to the Program Data Type Manager.

Data Types Table Clone

This action will create a new snapshot Data Types Table provide with the same data type filter settings, table filter settings and column filter settings. The program types showin in the snapshot view will be the types from the program that was in the source provider used to create the snapshot window.

You can rename any of the Data Type Table provider windows by right-clicking on the tab or the title area.
