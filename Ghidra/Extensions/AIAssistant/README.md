# AIAssistant – עוזר AI מובנה ל-Ghidra

תוסף שמוסיף ל-Ghidra חלון "עוזר AI" (מבוסס Claude של Anthropic) עם ממשק בעברית:

* **הסבר פונקציה** – מבצע דה-קומפילציה לפונקציה שבה נמצא הסמן ושולח אותה ל-Claude להסבר.
* **הצע שמות** – מציע שמות לפונקציה, למשתנים ולפרמטרים.
* **שאלה חופשית** – שיחה רציפה עם ה-AI (זוכר את ההקשר עד לחיצה על "שיחה חדשה").

## הגדרה

1. צור מפתח API ב-https://console.anthropic.com
2. ב-Ghidra: `Edit > Tool Options > עוזר AI` והדבק את המפתח
   (או הגדר את משתנה הסביבה `ANTHROPIC_API_KEY` לפני הפעלת Ghidra).
3. `File > Configure` (או `File > Configure > Analysis`) והפעל את `AIAssistantPlugin` אם אינו פעיל.
4. פתח את החלון דרך `Window > עוזר AI`.

המודל ברירת המחדל הוא `claude-opus-5-5` וניתן לשנות אותו באפשרויות.
הקוד של הפונקציה נשלח לשרתי Anthropic – אל תשתמש בזה על קבצים שאסור להוציא מהארגון.
