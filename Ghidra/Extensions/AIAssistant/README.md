# AIAssistant – עוזר AI מובנה ל-Ghidra

חלון "עוזר AI" בתוך Ghidra שעונה על שאלות על התוכנית הפתוחה, בעברית. העוזר לא מנחש:
הוא חוקר את התוכנית בעצמו בעזרת כלים, ומעביר אותך למקום שמצא.

## מה אפשר לשאול

* "איפה נמצא הקוד שבודק את הסיסמה?"
* "מה גורם להודעת השגיאה 'Access denied'?"
* "מי קורא לפונקציה הזו ומה היא עושה?"
* "איפה התוכנית מתחברת לאינטרנט?"

וגם שני כפתורים מהירים: **הסבר פונקציה** ו**הצע שמות** לפונקציה שבה נמצא הסמן.

בזמן העבודה החלון מציג כל צעד, למשל `🔎 מחפש מחרוזות 'password'`.

## הכלים שה-AI משתמש בהם

| כלי | מה הוא עושה |
|---|---|
| `search_functions` / `search_symbols` / `search_strings` | חיפוש פונקציות, סמלים ומחרוזות |
| `list_imports` / `list_entry_points` | פונקציות מיובאות ונקודות כניסה |
| `get_references_to` | הפניות צולבות (מי משתמש בכתובת/פונקציה/מחרוזת) |
| `get_callers` / `get_callees` | מי קורא לפונקציה ולמי היא קוראת |
| `decompile_function` / `disassemble` | קוד C מפוענח ואסמבלי |
| `get_program_info` / `get_current_location` | מידע כללי והמיקום הנוכחי של הסמן |
| `go_to` | מעביר את חלון הרישום למקום שנמצא |

כל הכלים לקריאה בלבד; העוזר לא משנה את התוכנית.

## ספקי AI נתמכים

| ספק | מאיפה מקבלים מפתח | מודל ברירת מחדל |
|---|---|---|
| Anthropic Claude | https://console.anthropic.com | `claude-opus-5-5` |
| Google AI Studio (Gemini) | https://aistudio.google.com/apikey | `gemini-flash-latest` |
| OpenAI ושירותים תואמים | לפי השירות | `gpt-5` |

"שירות תואם OpenAI" מכסה גם את OpenRouter, DeepSeek, Groq, Mistral, xAI ושרתים מקומיים
כמו Ollama (`http://localhost:11434/v1`) ו-LM Studio (`http://localhost:1234/v1`). לשרתים מקומיים לא צריך מפתח.

## הגדרה

1. ב-Ghidra: `עריכה > אפשרויות הכלי > עוזר AI` (Edit > Tool Options).
2. בחר **ספק AI** והדבק את המפתח המתאים (או הגדר משתנה סביבה לפני הפעלת Ghidra:
   `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`/`GOOGLE_API_KEY`, `OPENAI_API_KEY`).
3. אם התוסף לא פעיל: `קובץ > הגדרות תצורה` (File > Configure) והפעל את `AIAssistantPlugin`.
4. פתח את החלון דרך `חלון > עוזר AI`.

שים לב:
* הקוד והמידע מהתוכנית נשלחים לשרתי הספק שבחרת. אל תשתמש בזה על קבצים שאסור להוציא מהארגון
  (או השתמש בשרת מקומי כמו Ollama).
* המפתחות נשמרים בהגדרות הכלי של Ghidra כטקסט רגיל. אם זה מפריע, השתמש במשתני סביבה.
